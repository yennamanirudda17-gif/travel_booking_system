# travel_booking_system
A lightweight Core Java application simulating a basic airline ticketing platform. It features user registration, flight search by route and date, ticket booking with unique ID generation, reservation viewing, and cancellations. Built using core OOP principles and Java Collections for clean, efficient in-memory data management.
